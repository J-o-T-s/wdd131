Site Plan

Site Name

CreativeNest Tutorials

This name represents a growing hub for beginners learning digital skills such as drawing, animation, and basic tech tools. "CreativeNest" suggests a safe and supportive space for new creators.

Optional Domain: creativenest-learn.com

Site Purpose

The purpose of this website is to provide beginner-friendly tutorials in art, animation, and digital creation. The site will contain simple guides, downloadable resources, and a contact section for questions or collaboration requests.

Scenarios

  • “Where can I download beginner-friendly drawing practice sheets?”
  • “How do I start digital art if I have never used a drawing tablet?”

Color Schema

Main Blue (#1b57d0): used for headings and accents across the website.

Accent Orange (#ff6b35): used for buttons, highlights, and important notices.

Soft Background (#f4f8ff): used as the page background to maintain readability.

Typography

Poppins: Used for all headings (H1–H3) to create a bold, modern look.

Roboto: Used for the body text for simple readability and accessibility.
